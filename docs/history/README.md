# History

Finished plans and the session handoff log of the MVP, kept as a record of how
the code came to be. Not maintained: links and file names may be outdated, and
the older logs (`plan.md`, `progress.md`) are in Dutch.

The MVP started as a personal tool for one route (Amsterdam ⇄ Helsinki/Turku);
that route is now the demo route. Where the project goes next:
[`docs/roadmap.md`](../roadmap.md).
